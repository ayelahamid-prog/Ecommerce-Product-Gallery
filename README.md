
# ShopEase - E-Commerce Product Gallery

## Description
A responsive E-Commerce Product Gallery created using HTML and CSS Grid.

## Features
- Responsive product gallery
- CSS Grid layout
- Auto-fit and minmax properties
- Minimum product card width of 250px
- Hover animations
- Product images and prices

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Git
- GitHub
